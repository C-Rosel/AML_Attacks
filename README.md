# Adversarial Machine Learning (AML) Attacks
These assignments were created as part of the Adversarial Machine Learning research project under Dr. Jingdao Chen.

This repository contains three examples of AML attacks that can be performed against ML computer vision models:

1. Adversarial Patch Attack 

2. Data Poisoning Attack

3. LiDAR Spoofing Attack

All of these notebooks are designed to be run in Google Colab, but are also compatible with Jupyter. Please note that if being run locally, additional considerations for file paths and installing packages need to be taken into account.
